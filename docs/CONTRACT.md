# Working integration contract v1

Python package `echosight`; plain JSON dictionaries at module boundaries, NumPy arrays only inside numerical calls. Coordinates are right-handed metres, z up. Plane n dot x=d. Times are seconds. Source sample scale kappa is actual/nominal, alpha maps source nominal time to receiver nominal time. No ground truth passes into fitting.

Session dictionary: schema_version='1.0', session_id, sound_speed_m_s (343), sound_speed_std_m_s (0.6), source_clock_scale (1), source_clock_std_ppm (100), source_position_m [x,y,z], source_position_std_m (0.01), captures list. Capture: capture_id, receiver_position_m, receiver_position_std_m (0.01), recording_path, provenance ('simulated','measured','replayed'), optional sample_rate_hz. Probe dictionary defined by acoustics; stored at session['probe']. Initial supported scene: one stationary calibrated source, stationary receivers spread in 3D. Missing poses/calibration produce diagnostics, not fabricated geometry.

Signals public API (acoustics owner): generate_probe(config=None)->(mono float64 array, probe dict); process_recording(samples, sample_rate_hz, probe, capture_id, sound_speed_m_s=343.0)->dict with status ('ok','rejected'), diagnostics list, clock dict, candidates list. Candidate: candidate_id, delay_s (excess source-buffer delay), delay_std_s, amplitude; direct_std_s on result. Preserve relative/absolute clock distinction. cancel callback optional if practical. Synthetic API: simulate_session(output_dir, scenario='room', seed=1)->Path to session.json; writes raw PCM WAV and separate truth.json, never inserts truth into session. Agent defines additional scenarios and options and documents them.

Inference public API (inference owner): infer_scene(session, observations, cancel=None, progress=None)->JSON dict. observations are signal output plus capture_id, receiver_position_m and receiver_position_std_m. Result includes schema_version, status ('ok','partial','ambiguous','no_result','cancelled'), surfaces, hypotheses, diagnostics, guidance, dimensions, provenance. Surface includes stable surface_id, normal, offset_m, support evidence, uncertainty, vertices_m, triangles, extent_status='unknown'. Infer planes from unlabeled candidates, exclusive assignment, physical residual checks, null comparison; preserve global ambiguities. No required room enclosure. Baseline API infer_baseline(session, observations)->same major shape. Geometry helper APIs chosen/documented by inference owner.

Storage/backend public API (backend owner): validate_session(dict)->dict or ValueError; load_session(path)->dict with paths resolved; import_recording(path, destination_dir)->dict with stored recording_path, sha256, samples metadata; read_recording(path)->(samples, rate); SessionStore(root) manages sessions/jobs/recovery/export. HTTP using standard library or existing pinned lightweight dependency, loopback only by default; create_server(root, host='127.0.0.1', port=8765, processor=None)->server. Coordinator provides processor(session,cancel=None,progress=None) -> result. Implement API docs, resource limits, cancellation, raw recording upload, result export and replay.

Coordinator owns pipeline.py, cli.py, package setup, README, STATE, integration tests and publication. Acoustics owns signals.py, simulation.py, tests/test_signals.py, docs/ACQUISITION.md, docs/SIGNAL_MODEL.md. Inference owns inference.py, geometry.py, tests/test_inference.py, docs/INFERENCE.md. Backend owns storage.py, api.py, tests/test_storage.py, tests/test_api.py, docs/API.md, schemas/. Evaluation owns evaluation/, tests/test_evaluation.py, docs/EVALUATION.md, docs/SOURCES.md, evidence/external*. No overlapping edits; propose contract changes by message. Tests use unittest so NumPy/SciPy are the only initial runtime dependencies.
