# Waveform and timing model

Status: implemented and tested on generated recordings; no local iPhone validation.

`generate_probe` renders seven 40 ms tapered linear sweeps from 2–15 kHz at nominal 48 kHz, with starts separated by 220 ms in **one** 1.64 s buffer. These are audible signals; the selected band is a software fixture, not a claim that every device delivers it. Repetitions support relative-clock estimation and response consistency. Quiet space between them isolates an 80 ms early-echo window. Configuration bounds prevent unbounded probe allocation. The generated manifest stores all actual sample indices, band, nominal rate, timing convention and deterministic float-waveform hash.

For a fixed source and receiver, emitted nominal source time t and delivered receiver time u obey `u = alpha*t + b`. The intercept contains record offset, direct propagation and transducer latency. Fitting a line to all seven direct arrivals estimates alpha; the residual tests this affine assumption. A maximum residual above max(2 receiver samples,100 microseconds) rejects the capture. Slope outside ±5000 ppm is rejected. Waveform tests exercise ±clock correction and non-affine distortion, not this entire limit under every noise condition. Motion can mimic clock drift. Stationarity is a required acquisition condition.

The processor searches for the earliest complete significant repeated arrival train, with each peak exceeding both a robust noise threshold and 10% of the recording's strongest correlation. It does not equate strongest with direct. An additional gate searches for weaker repeatable arrivals more than 1 ms before the selected reference, using a threshold above robust noise and five times the known pulse autocorrelation sidelobe bound (with a 1.5% relative floor). It rejects these captures as `direct_reference_ambiguous`, retaining timing diagnostics and earlier offsets instead of promoting a weak arrival into geometry. A sufficiently weak, nearby or blocked direct arrival can nevertheless be absent. This is explicitly reported as `direct_path_assumed`, not solved by statistical confidence. Truncation, pilot loss, clipping, silence, a receiver rate unable to support the full probe band, and cancellation return rejected observations. Samples remain available in storage.

After the fit, original received waveform segments are evaluated at `u=alpha*(t_start+t_local)+b`. This corrects relative rate before final correlation. The emitted pulse is the matched filter; the output estimates the band-limited room response convolved with the pulse autocorrelation, not a calibrated full-band impulse response. Median aggregation over repetitions suppresses intermittent noise. Retained peaks must recur in at least 70% of repetitions. The extraction threshold is at least 7% of the strongest response, so weak paths near a dominant reflector are intentionally sacrificed to reject matched-filter sidelobes. The candidate budget is 18, with an explicit truncation diagnostic. Amplitude is relative to the detected direct response, not reflectivity or a material classifier.

Echo delay is `delta_t=(u_echo-u_direct)/alpha`, in **source-buffer seconds**. If `kappa=F_source_actual/F_source_nominal`, physical delay is `delta_t/kappa`. Therefore reflected path length is `D+(c/kappa)*delta_t`, where D is the known source–receiver distance. Alpha does not independently calibrate kappa or sound speed c. The session records both common scale uncertainties, and the inference module propagates them. No delay is blindly divided by two.

Peak localization uses a local quadratic maximum. Its uncertainty floor is max(0.5 source samples, 0.5/bandwidth), about 38.5 microseconds for the default pulse. Independent peak scatter can enlarge it. Relative-slope uncertainty is provided separately in `clock.alpha_std`; inference adds its shared within-capture covariance `(alpha_std/alpha)^2 outer(delays,delays)`. `direct_std_s` is separate shared uncertainty across all echoes from one recording; do not count it as independent for every path. Localization precision does not certify unbiased transducer delay or resolve overlapping paths. The minimum candidate separation is max(350 microseconds,3/bandwidth), about 12 cm excess path at 343 m/s. Nearby reflectors may produce a single merged path and must not receive duplicate independent support.

The response export includes its start delay relative to direct arrival, nominal source-grid sample rate and signed samples. These values permit frontend inspection and later A→B→A acoustic-change tests; a changing response alone does not localize a changed object.

# Simulation and restrictions

`simulate_session(directory, scenario, seed, capture_count=None)` writes lossless PCM16 recordings, the emitted probe WAV and an input manifest. It writes `truth.json` separately; no fitting function receives it. By default eight known receiver stops span three coordinates. Optional `capture_count` supports 4–24 stops; additional stops use a separate random stream and preserve the first eight default recordings byte-for-byte. The frozen evaluation fixtures remain unchanged. These can be occupied by four phones in two placements. One source is fixed. The room fixture contains six independently simulated first-order reflectors including floor and ceiling, not an extruded 2D solution.

Scenarios: `room`, `partial` (three surfaces), `coplanar` (global mirror ambiguity), `null` (direct only), `clutter` (independent unstructured paths), `mismatch` (coloration and unmodeled extra paths), `reflector` (an additional tilted plane), `warp` (non-affine clock), `four_views` (limited acquisition). Seed changes dimensions, poses, amplitudes, relative rates and offsets. Fixture images and dimensions are evaluation truth, never geometry returned by the solver. Source/receiver positions are supplied calibration and labeled accordingly.

Fractional delays use interpolation instead of integer impulse indices. This is a controlled image-source simulator, not a physical room or finite-object scattering model. Specular planes have no demonstrated physical edges. Frequency-dependent directivity, diffuse scattering, absorption, occlusion, diffraction, air turbulence, real transducer groups and OS processing are not comprehensively simulated. The mismatch fixture probes a subset of these failures. External measured impulse-response tests are separately labeled: convolving a generated probe with a measured response is measured-response-derived simulation, not a fresh physical recording.

## Measured-response repetition-spacing check

The initial dEchorate replay accepted 23/25 measured-response-derived waveforms with the 220 ms period. Two captures had a first-pilot arrival inconsistent with their later, mutually consistent arrivals. Keeping every measured response intact and changing only repetition spacing to 1 s made all 25 timing-consistent in the evaluator's targeted experiment. This supports overlapping reverberant tails as the cause in these replay cases; it does not prove every real clock rejection is reverberation. The original rejection remains preserved in evaluation evidence. Subsequent inspection found that one five-channel case still selected a dominant reflection while earlier repeatable energy lay below the initial direct threshold. At one-second spacing the added direct-reference gate rejects all five difficult channels and retains the other20. At the default220ms spacing, one difficult channel is still accepted with a5.58ms coordinate-model discrepancy. Baseline default acceptance20/25 included that suspect channel and one rejection elsewhere; a subsequent clock-acquisition improvement restores that other channel (21/25) without fixing the suspect direct reference. These counts are not direct-path accuracy, and the earlier blanket five-channel-rejection claim was incorrect. Stable clock timing therefore does not establish a correct direct reference. Coordinate-based direct-arrival discrepancies in the other external cases also remain uncalibrated and are reported as model compatibility, not independently annotated timing accuracy. Use `generate_probe({'period_s': 1.0})` for a reverberant-room trial, increasing the emitted buffer to 6.32 s. The same detector and timing thresholds apply. All external geometry remains ambiguous because its available receiver locations are collinear. No independent measured echo labels were loaded, so timing-consistent signals are not measured echo accuracy.
