## Separate status, without an optimistic percentage

- **Software implementation coverage:** working baseline core/API/CLI, import/store/replay and bounded planar inference. Controlled scene-change validation, calibration revision flow and several physical-model diagnostics remain incomplete.
- **Synthetic validation:** original and twelve-view suites pass, with original misses preserved. This covers a narrow family; higher-order/finite-reflector/strong distortion/wrong-model families are not yet adequate.
- **External measured-data validation:** 25 measured laboratory responses used in hybrid playback replay; 20 accepted, 5 direct-reference rejections. No external measured 3D accuracy established.
- **Own-device physical validation:** none. No iPhone/MacBook accuracy claim.
- **Unresolved scientific capability:** path-order identity, trustworthy source/direct reference, arbitrary finite reflector visibility/diffraction, wrong-model uncertainty, and causal scene-change interpretation. Some can be improved in software now; others require specifically designed measurements.

## Active priority queue

1. Reproduce coherent higher-order phantom surfaces and wrong-model overconfidence; compare alternatives with identical observations and add justified interpretation/abstention.
2. Stress source/direct-reference and signal extraction under distortion/overlap; quantify the detectable versus unobservable boundary.
3. Secure consistent raw snapshot/provenance; add safe calibration revision and interruption contracts.
4. Obtain usable measured spatial geometry and freeze independent harder families before execution.
5. Implement controlled repeat-acquisition comparison and more operational hardware acceptance after physical-data contracts settle.
6. Integrate, adversarially review, reproduce and push each coherent improvement; update this matrix with exact code/evidence.
