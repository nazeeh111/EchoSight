# Bounded early-response source qualification, frozen before generation

Purpose: test whether actual signed early responses distinguish a rigid second emitting center from a real fixed nearby reflector. This is a development diagnostic, not a new backend capability or calibrated hypothesis test. Original path-interpretation seeds1301/1307 and their failures remain untouched.

New development seeds2401 and2411 only. Twelve cases: single-emitter room, two-emitter room, single-emitter room with a near horizontal reflector, direct-only null, single-emitter room with receiver-dependent filter mismatch, two-emitter room with an unmodeled secondary-driver phase filter. No scene resampling. Four noncoplanar sources and12 receivers, all source orientations declared constant. Use original source-relocation geometry/calibration draw convention, except receiver height lower bound0.95m and a near reflector at z=0.8m, so this close-reflector family has physical same-side support. Every baseline and diagnostic sees identical raw PCM, supplied poses and probe definitions; no path labels enter fitting.

Use 48kHz, 2–14kHz repeated chirp,7 repetitions; source FIR[.82,.13,-.045,.025], receiver FIR[.94,.045,-.018,.006], normalized49-tap Hann-sinc fractional delay, affine recorder±250ppm and40–80ms offsets, noiseσ.00012 and fixedgain.45. Preserve actual source clockκ1.00035, c343.45 and supplied effectivev343±.6, common sourceσ3mm plus independentσ4mm, shared receiverσ6mm. Source location/clock definitions and full covariance are carried into immutable processing. Quantize once to PCM16; overload is a failure, not normalization permission.

Rigid secondary displacement is[.18,-.11,.07]m in the room frame, relative amplitude.65, driver delay80microseconds. Render its direct and six first-order room paths independently. For phase-mismatch dual, apply secondary-only FIR taps[1,-.35,.18] at offsets[0,5,13]samples. Single receiver mismatch uses a deterministic bearing-varying signed filter[1,.18*sin(bearing),-.08] at offsets[0,3,9]samples on the entire received response. These are controlled surrogates, not measurements of a device or material. Near reflector is a partially transmitting infinite horizontal plane at z=.8m with amplitude.35*direct/path; no occlusion is claimed. Direct-only null has no physical reflector.

Run immutable de8442b raw processing first; preserve admission, candidate counts, shared covariance and full signed responses. Diagnostic inputs are the processed responses, surveyed poses and calibration only. Record annotations separately for scoring. No perfect secondary arrival labels or true filter coefficients enter diagnostic fitting.

Use receiver IDs0..7 at every source for fitting (32records); IDs8..11 for withheld waveform prediction (16records). Fewer than three accepted receivers at any source or fewer than12held records means diagnostic unavailable. Learn a common direct-response kernel by median of peak-aligned, signed-normalized training responses. Preserve the known bandwidth; use full waveform residuals, not peak labels. A shared empirical kernel may absorb an unresolved secondary source; this is a limitation, not permission to use truth.

Compare three models on exactly the same early waveform samples: single component; primary plus secondary with delay(norm(s+δ-r)-norm(s-r))/v+τ; primary plus real fixed-plane image with delay(norm(Hs+2dn-r)-norm(s-r))/v+τ. Both two-component models have4global parameters and allow an unknown constant extra delay bounded±150microseconds. Allow bounded per-record alignment±2samples and linear component gains as nuisance terms; this gives all models the same treatment of phase/amplitude/reference uncertainty. The plane must have physical same-side reflection geometry. Search bounds and starts must be recorded in source before any generation and applied equally across cases; no tuning to resulting geometry.

A source-model flag requires held normalized waveform squared error at most70% of BOTH the single-component and near-reflector competitor, improvement in at least12held records, a nondegenerate secondary component and an interior search solution. These are frozen engineering thresholds, not false-alarm probabilities. Report all residuals, source-parameter estimates, shared-survey/clock sensitivity and any unavailable cases. There is no hardware certification from passing.

Evaluate the tentative flag's consequence conservatively by clearing definitive geometry in flagged cases, without changing the main runtime or claiming the remaining geometry is correct. On qualified single-source room, near-reflector, direct-null and filter controls, require no flag and retain every baseline-supported true surface. On two-source cases, report true surfaces lost and false surfaces removed; losing all mapping may be honest source-calibration-needed but is not successful room reconstruction. A branch that cannot discriminate the real-near-reflector/filter controls must not be promoted.

This design may fail. Preserve failure and close or narrow the branch instead of adjusting criteria on these answers. No extra held-out claim is established by these development cases. A later hardware experiment must test source-channel routing, orientation and driver delay independently.
