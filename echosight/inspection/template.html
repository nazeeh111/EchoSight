Display encoding and saved array identities

Axial grayscale is round(clip(amplitude / global volume maximum, 0, 1) × 255). Both lateral display axes reverse their native indices. Display y increases downward. The 1-based source depth is the bin number multiplied by bin spacing. Native array indices shown in the viewer are zero-based.

The generated report’s volume.npy, depth_m.npy and maximum_amplitude.npy retain numerical precision. Threshold diagnostics JSON records native crossings and maxima.
